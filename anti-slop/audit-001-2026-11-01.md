# Windows native UI AFTER audit

Scope: source at `183c11f`; actual Windows screenshots from `work/artifacts/windows-ci-015d18a/output/proof/`; current catalog-only previews from `work/artifacts/windows-preview-final/`. This is a usability audit against the approved macOS parity specification, not a proposed redesign. No application files were changed during the audit.

## Findings

1. **HIGH, R-25/R-39: the Windows season selector arrow lacks usable contrast.** Actual `series.png` pixels show the dominant arrow color `#353637` against `#252C36`, approximately **1.16:1**, below the human skill's 3:1 non-text UI requirement. The existing `ComboBox` relies on a platform-derived indicator color. Use an explicit indicator from the existing approved palette for the season and country selectors.
2. **HIGH, R-32: player-wide shortcuts intercept focused controls.** In a read-only probe of the actual production QML overlay, Space did not open the focused subtitle button, Right left the focused volume slider at 30, and Up instead ran the global volume shortcut to 35. `PlayerWindow.qml` enables application-wide shortcuts whenever playback is active and a menu is closed, regardless of focused controls or active window. Let controls own their standard keys and restrict playback shortcuts to the active video/overlay window. Preserve the existing two-second idle hide.

Evidence for finding 2: `work/artifacts/windows-ui-readonly-audit/smoke.json`, `focusedControlAudit`. The temporary audit executable/source were outside the application tree. This local probe establishes QML keyboard dispatch, not Windows codec playback.

## Evidence and limits

- Original wordmark, favicon and poster sound SHA-256 values exactly match their existing website/macOS sources.
- The 900×620 account screenshot fits the sidebar, account card and action row without horizontal overflow; lower settings remain vertically scrollable. The approved minimum is a desktop window, not a mobile layout.
- Home has a clear heading, cinematic hero and ordered poster shelves. The current preview retains the heading and hero after initial welcome and archive-to-home navigation.
- Live cards use landscape frames; `Artwork.qml` uses `PreserveAspectFit` with margins for channel artwork. Fixture channels have no supplied logos, so screenshots verify the honest title fallback, not real provider-logo appearance.
- Login, welcome, empty search and expired access are rendered in the reviewed screenshots. Loading, retry and player error states exist in QML. A separately delayed loading-state capture was not supplied for this audit.
- Sidebar, search and card controls expose visible focus styling and accessible names in source. This audit did not run Narrator or claim a complete screen-reader certification.
- The final preview records `catalogOnly:true`, `fixtureHttp:true`, `qmlErrors:[]`, `passed:false`, `localMediaPlaying:false`. It is not native Windows playback proof. Actual Windows 015d rendered playback before failing an older double-click test; final native CI must separately pass.
- The current primary text change is already included in source: dark `#07090C` on accent `#FF3545` is approximately 5.55:1; on hover `#E52D3D` approximately 4.53:1. Disabled controls are not treated as active-text contrast failures.
